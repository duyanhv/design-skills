## Implementation, not design

Use [Apple developer documentation](https://developer.apple.com/documentation/) for APIs and
availability. A design recommendation and an API capability answer different questions; see
[platforms.md](../context/platforms.md).

## Two cautions about this table

**A page title is a navigation aid, not evidence.** It does not establish that a particular
requirement exists on the page, and several pages cover multiple platforms with different answers.

**Pages move.** Navigation bars merged into Toolbars, and the old URL serves the Toolbars document
instead of failing. If a link here disagrees with the live site, the live site is right; please open
an issue. `bun run links` in this repository checks these URLs against Apple's own page data.

When a number matters, record its unit, platform, component state, and exception along with the
source section. Do not substitute a remembered cross-platform default for the value on the page.
